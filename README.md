# Casalucca - Home & Lifestyle E-Commerce Website

A modern and elegant e-commerce website frontend for Casalucca, a home & lifestyle brand offering a curated collection of products for comfortable, elegant living.

## 🏠 About

Casalucca specializes in high-quality home essentials including:
- 🍽️ Tableware
- 🍳 Kitchen Sets
- ☕ Coffee Mugs
- 🛏️ Bed Linens
- 🌙 Duvets
- 🧖 Towels
- 🕯️ Candles
- 🏠 Home Décor Accessories

## ✨ Features

- **Modern Design**: Clean, elegant interface with smooth animations
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Product Categories**: Easy navigation through different product types
- **Shopping Cart**: Fully functional cart with add/remove/quantity controls
- **Product Filtering**: Filter products by category
- **Smooth Scrolling**: Enhanced user experience with smooth page transitions
- **Interactive UI**: Hover effects, animations, and visual feedback

## 🚀 Getting Started

### View the Website

Simply open `index.html` in your web browser:

```bash
# Option 1: Direct open
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux

# Option 2: Using Python's built-in server
python3 -m http.server 8000
# Then visit http://localhost:8000

# Option 3: Using Node.js http-server
npx http-server
```

## 🎨 Design Features

- **Color Palette**: Warm, earthy tones with accents of brown and gold
- **Typography**: Playfair Display for headings, Inter for body text
- **Layout**: CSS Grid and Flexbox for responsive design
- **Animations**: Smooth transitions and hover effects
- **Icons**: Unicode emojis for visual appeal

## 🛠️ Technologies Used

- HTML5
